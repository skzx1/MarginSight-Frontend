## ข้อจำกัดหลักฐาน

CSV retry checkpoints อยู่ใน component ของการนำเข้ารอบนั้น ไม่ใช่ durable import job ข้าม reload; เมื่อ response สูญหายต้องตรวจ catalog/SKU ก่อนลองนำเข้าใหม่. ราคา/สต็อกยังไม่มี API บันทึก. Finance demo expenses/store preferences อยู่ browser ไม่ใช่ real ledger persistence.

การแจ้งเตือน API truncation ทดสอบด้วย unit fixtures ไม่ได้สร้าง >50 REAL orders เพื่อทดสอบบน AWS. ไม่อ้างทดสอบ Bedrock inference/OCR/LINE/live platform adapters/two-user Cognito isolation ใหม่ในรอบนี้; blockers เดิมใน status/plan ยังคงอยู่. Localhost browser เข้าไม่ได้ในรอบนี้ จึงใช้ cloud MOCK UI checks แทน ไม่อ้าง local-browser pass.
