# เลือกแพลตฟอร์มและแคมเปญใน Playground — 18 ต.ค. 2569

1. เปิดเมนู Playground (`/login/#playground`) เลือกสินค้าที่มีออเดอร์ในเดือนที่เลือก.
2. เลือก Shopee / Lazada / TikTok Shop เพื่อลองขายสินค้านี้บนแพลตฟอร์มนั้น. หน้า “ถามผู้ช่วย” (`#assistant`) ใช้หน้าสนทนาและประวัติแชตรุ่นใหม่จาก main; ไม่วางฟอร์มทดลองแคมเปญซ้ำในหน้านั้น.
3. เลือกหมวด ประเภทร้าน และโปรแกรม: PRIME/LiveXtra, Lazada Premium Package หรือ TikTok BCD/Flash Sales. รายการมาจาก Backend ที่ตรวจสิทธิ์ร้านแล้ว ไม่ใช้รายการ fallback ปลอมเมื่อ API ไม่พร้อม.
4. กรอกค่าคอมมิชชั่นและ VAT ตามร้าน ตรวจค่าชำระเงิน/ฐาน ค่าส่งผู้ซื้อและสิทธิ์ยกเว้น. อัตราไม่ทราบต้องเว้นว่าง ไม่กรอก0เพื่อให้ผ่าน. อิเล็กทรอนิกส์ PRIME/LiveXtra มีตัวเลือกอัตราตามสิทธิ์. Growth Fee ของ TikTok ยังมีแม้ไม่เลือกแคมเปญ; BCD/Flash ไม่คิดซ้ำใน SKU เดียว.
5. ติ๊กยืนยันสมมติฐาน แล้วกดคำนวณตามตัวเลือก หรือถามส่วนลดเป็นเปอร์เซ็นต์/ราคาคุ้มทุน/เปรียบเทียบไม่เข้าแคมเปญ. การคำนวณโหมดนี้เรียก Backend engine โดยตรง ไม่ใช้โมเดล AI หรือโควตา inference. ประวัติแยกตาม SKU เดือนและสมมติฐาน; เปลี่ยนค่าแล้วต้องยืนยันใหม่.
6. อ่านผลประมาณการ ดูออเดอร์ต้นทาง รายการค่าธรรมเนียมและหลักฐาน. ข้อมูลไม่ครบแสดงกำไรไม่ได้. การกดปุ่มนี้ไม่สมัครแคมเปญให้ร้าน ไม่เปลี่ยนออเดอร์และไม่บันทึกสิทธิ์ยกเว้นจริง.

ราคา/ต้นทุนอ้างอิงออเดอร์ล่าสุดแบบ SKU เดียวของเดือนนั้น ผลจำลองไม่ใช่ยอดหักจริง. รายการที่ยังไม่รองรับ เช่น Shopee Flash Sale Dynamic Discount ที่ต้องใช้ Seller Offer Price แยก, สินค้ายังไม่มีออเดอร์, พรีออเดอร์ และ Affiliate/ค่าร่วมจ่ายที่ไม่ได้บันทึก ไม่ถูกแสดงเป็นการเชื่อมต่อที่ทำงานแล้ว. ใช้ยอด settlement จริงแทน estimate เมื่อมีหลักฐาน ห้ามนำไปหักซ้ำ.

API: GET assistant-options / POST assistant-scenarios ภายใต้ stores/{id} และสิทธิ์เดิม. ตัวเลขจาก canonical API engine; browser แปลงหน่วย input เท่านั้น สูตร generated preview ไม่เปลี่ยน. รองรับภาษาไทย/อังกฤษของตัวควบคุม ชื่อหมวดและหมายเหตุจากแหล่งอ้างอิงเป็นภาษาไทย.
