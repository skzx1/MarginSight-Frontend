HELPER SPEC (new file web/src/lib/signed-money.ts, pure; wraps money(), does not change it)
  type PL = 'gain' | 'loss' | 'zero' | 'missing'
  plKind(satang: number|null|undefined): PL                      // -0 -> 'zero'
  signedBaht(satang, locale='th'): string                         // "+฿118.30" | "−฿53.00" | "฿0.00" | "—"   (U+2212, money(Math.abs(v)))
  profitParts(satang, locale='th'): { kind: PL; label: string|null; amount: string; text: string; spoken: string }
      text   = "ขาดทุน −฿53.00" | "Loss −฿53.00"   This is the ONE visible rule for level values everywhere: KPI, rows, tooltips, assistant sentences, clipboard.
               In sentences it is used as a tag after a "กำไร/ขาดทุนสุทธิ:" lead-in, e.g. "เดือนนี้ กำไร/ขาดทุนสุทธิ: ขาดทุน −฿53.00 จาก 12 ออเดอร์".
      spoken = "ขาดทุน 53.00 บาท" | "Loss of 53.00 baht"   (sr-only / aria-label only; the word carries the sign, so no "minus" is read aloud)
  (the 'phrase' variant is REMOVED)
  signedPercent(value: number|null, locale='th', digits=1): string // "+12.4%" "−3.2%" "0.0%" | "—"   rounding happens FIRST; a value that rounds to 0 (incl. -0.04, 0.04, -0) -> "0.0%" with no sign
  deltaParts(change: number|null, unit: 'pct'|'pp', locale): { dir: 'up'|'down'|'flat'|'none'; text: string; spoken: string }
      dir is decided on the ROUNDED value. flat -> no arrow, text "0.0% · ไม่เปลี่ยนแปลง" / "0.0% · no change". none -> "ไม่มีฐานเปรียบเทียบ".
  React: ProfitAmount becomes a thin view over profitParts (visible text aria-hidden + sr-only spoken). <Delta> renders an SVG triangle (aria-hidden, neutral colour) + signedPercent + "เทียบช่วงก่อน".

DECISION (fix pass after challenger review)
- Level values use ONE rule: label + sign, "ขาดทุน −฿53.00", in every surface including sentences. Why:
  (a) The number token "−฿53.00" is identical everywhere, including the sign-only fallback (dense tables, axes), so the two forms never disagree.
  (b) It stays colour-free with two cues: the word, plus the sign for EN or digit-scanning users.
  (c) Double-negative risk: the label is used as a status tag next to the number, never as a verb in prose ("ขาดทุนไป −53" is banned), and headers read "กำไร/ขาดทุน...". The residual risk is ASSUMPTION; test it with sellers.
- Headers or labels above a value that can be negative must say "กำไร/ขาดทุน" / "Net profit/loss", never only "กำไร".
  Affected: finance KPI "กำไรสุทธิ", channel table "กำไรสุทธิ", orders column "กำไร", overview profitCard, chart legend/tooltip names, assistant result label.
  New copy key netProfitLoss covers these. Ranking titles such as "กำไรสูงสุด 5 อันดับ" may stay because they name the sort, not the value.
- Zero or rounds-to-zero delta is neutral everywhere: no arrow, no sign, "ไม่เปลี่ยนแปลง". Fixed in indicators.html (R.delta + edge table).
