4.2 Composer rules

  • Enter (no Shift, not composing, desktop) → send. Guard: e.nativeEvent.isComposing || e.keyCode === 229 || composingRef (composingRef from compositionstart/compositionend). [V] current code checks isComposing only; Chrome passes (probe). [A] WebKit/Safari can deliver the committing Enter with isComposing=false → add 229 + flag. Thai keyboards on desktop usually type without composition; mobile predictive keyboards (Gboard/iOS) use composition [A].
  • Touch (pointer:coarse): Enter = newline, send via button (A2, needs owner OK).
  • Shift+Enter newline [V probe]. Textarea grows 48→160px then scrolls (existing).
  • Send disabled when draft is whitespace or archive not ready; Stop replaces Send while pending (existing). Stop is a type=button so Enter in textarea can't trigger it.
  • Context chips (period, product) sit inside the composer card, open dialogs, return focus to textarea after apply (existing).
  • No attach button (A5). If the owner wants a bill path: a text link "อ่านบิลซื้อ ›" to #receipts beside the chips, not an attach affordance.
  • Draft persists per session (localStorage) across navigation and reload [V probe] — so no unsaved guard is needed for the assistant.

9. Cross-cutting rules

  • Targets: every control ≥44×44 CSS px (repo standard; spec's 36px buttons rejected). Inline text links inside sentences exempt (WCAG 2.5.8 inline exception) [R].
  • Focus ring: 3px, visible on composer card via :focus-within.
  • Reduced motion: no arrive animation, no smooth scroll, no count-up (existing in assistant + finance); drawer/sheet open without slide; typing dots static text.
  • Live regions: one polite region per concern — catalog result count, overview order count, assistant reply, copy confirmation. Errors use role=alert once (not re-announced on re-render).
  • Loading/empty/error: skeletons are aria-hidden with a separate sr status; empty states always offer the one action that resolves them (clear filters, add product, change period).
  • Unsaved changes: keep store-settings guard; optional F1 guards use the same registerGuard (single slot — only the mounted form registers).
  • Language: switching language must not reset drafts or dialogs [A — not probed].
