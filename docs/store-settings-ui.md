# ข้อมูลร้าน — ปรับ UI/UX

18 ตุลาคม 2026 · local static export · ภาพตรวจใช้ข้อมูลสังเคราะห์

## สิ่งที่ปรับ

- Container กว้างสูงสุด1024px, padding ด้านข้าง24px/ด้านบน32px และระยะระหว่างส่วน24px ใช้ canvas `#F9F8F6` กับ forest `#1E2D1B` เฉพาะหน้าข้อมูลร้าน
- Header มี H1 เดียว ตัดชื่อร้านซ้ำและ dropdown มุมขวา รวมข้อมูลจำลอง/โควตาไว้ใน metadata pill
- ตัวเลือกร้านอยู่ในแถบนำทาง ใช้ได้ทั้ง desktop, tablet แบบย่อ/ขยาย และ topbar บนมือถือ
- จัดการข้อมูลอยู่ส่วนแรก: การ์ดทั้งใบกดได้ พร้อมไอคอน ชื่อ คำอธิบายสั้น และลูกศรเดียว กริด2คอลัมน์ตั้งแต่768px และ1คอลัมน์บนมือถือ
- ข้อมูลร้านค้าใช้ฟอร์ม2คอลัมน์ ช่องที่ยังบันทึกไม่ได้ใช้พื้น/ขอบ/ข้อความชุดเดียวและไอคอนล็อก
- การแจ้งเตือนเรียงภาษา/เกณฑ์มาร์จิ้นในแถวแรก และอีเมล/รายงานในแถวถัดไป ภาษาเป็น segmented control ที่ยังใช้งานและจดจำในเครื่องตามระบบเดิม
- เปลี่ยนแถบเตือนเต็มหน้าเป็น callout สั้นในหัวการ์ด พร้อมคำอธิบายข้อจำกัด ปุ่มบันทึกอยู่ขวาล่างและปิดใช้งานอย่างชัดเจน
- รักษาเส้นทางนำเข้า/OCR/กฎ/ตรวจยอด, LINE, สร้างร้าน และออกจากระบบ ไม่แก้ API หรือสูตรเงิน

## ข้อจำกัดจริง

บริการบันทึกโปรไฟล์และการแจ้งเตือนยังไม่พร้อมทั้งร้านเดโมและร้านจริง จึงคงช่องและปุ่มเหล่านั้นปิดใช้งาน ไม่สร้างการบันทึกปลอมหรืออ้างว่าส่งอีเมลแล้ว

## ไฟล์

- `web/src/app/components/store-settings.tsx` และ `store-settings.module.css`: เนื้อหาและ style เฉพาะหน้านี้
- `web/src/app/screens/store.tsx`: ส่งต่อ StoreSettings โดยคง LineConnection เดิม
- `web/src/app/components/shell.tsx`: header และตัวเลือกร้านเฉพาะ screen=store
- `web/src/app/login/page.tsx`: ส่งสถานะ guest ให้ metadata

## การตรวจในเครื่อง

- Production build ผ่าน รวม TypeScript และ pinned preview integrity; ไม่รันชุด automated tests ในงานรอบนี้
- Browser TH/EN ที่390,768,1024,1440,1920px: H1หนึ่งตัว ไม่ล้นแนวนอน ฟอร์มและเครื่องมือเป็น1คอลัมน์บนมือถือ/2คอลัมน์บนtabletและdesktop; mainสูงสุด1024px
- เป้ากดในเนื้อหาสูงอย่างน้อย44px; เปิดทางนำเข้าและอ่านบิลจากการ์ดได้; เปิดตัวเลือกร้านบนมือถือได้; ภาษาเปลี่ยนได้
- คู่สีรองที่ระบุใน CSS รวมข้อความในช่องล็อกมี contrastต่ำสุด4.62:1; browser runtime errors=0
- ภาพ hover/focus และทั้งสองภาษาอยู่ใน ignored `.impeccable/review/store-settings/` พร้อม `measurements.json`
- Finish review แบบ inline ตามคำสั่งไม่ใช้ subagents; ไม่มี AWS deployment

ระหว่างส่งมอบมีการ merge งานอื่นใน workspace และเกิด conflict ใน `web/src/app/screens/assistant.tsx` หลัง build/เก็บภาพข้างต้น งานนี้ไม่ได้แก้ไฟล์ดังกล่าว ผล build ข้างต้นเป็น snapshot ก่อน conflict ต้อง resolve merge แล้ว build รวมใหม่ก่อนเผยแพร่

## ควรตรวจด้วยตนเอง

1. บนมือถือจริง: scroll จนสุดหน้า safe area และปุ่มใต้ navigation
2. ร้านที่มีหลายร้าน: สลับผ่านตัวเลือกในแถบนำทาง ตรวจชื่อและข้อมูลของร้านที่เลือก
3. VoiceOver/NVDA: ชื่อการ์ด ปุ่มภาษา และคำอธิบายช่องที่ยังปิดใช้งาน
